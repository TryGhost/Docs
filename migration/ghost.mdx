This guide walks you through moving from a self-hosted Ghost instance on your own server to Ghost(Pro). The same steps work for moving between any two Ghost sites, or for creating a copy of your site for development.

## Export your data

Start by exporting your site data from Ghost Admin, then copy your images from the server.

### Export from Ghost Admin

Log into Ghost Admin on your self-hosted site and go to **Settings → Advanced → Import/Export**. Open the **Export** tab and click **All data**.

<Frame>
  <img src="/images/ghost-export-all-data.png" alt="The Export tab in Ghost Admin's migration tools, showing the All data and Post analytics buttons" />
</Frame>

Choose what to include, then click **Export**. Keep the dialog open until the download finishes.

<Frame>
  <img src="/images/ghost-export-data-modal-self-hosted.png" alt="The Export data dialog on a self-hosted site, with checkboxes for content & settings, members, post analytics, themes, and redirects & routes" />
</Frame>

Your browser downloads a single `.zip` file containing:

| What you selected | File in the zip |
| --- | --- |
| Content & settings | `export.json` |
| Members | `members.csv` |
| Post analytics | `post-analytics.csv` |
| Themes | `themes/{theme-name}.zip` (one per installed theme) |
| Redirects & routes | `routes.yaml` and `redirects.yaml` |

### Copy your images

Images and other media aren't part of the self-hosted export, so you'll need shell access to your server to copy them. If you're unable to get shell access, ask your web host for a zip of your images directory.

<Note>
The commands below assume you followed the [Ubuntu guide](/install/ubuntu/) to set up your instance. If you used another method, adapt the paths to suit.
</Note>

Once you're logged in to your server, `cd` to the `content` directory and zip the `images` directory with all its contents:

```bash
cd /var/www/ghost/content
zip -r images.zip images/*
```

Make sure your `images` folder only contains images. Other file types may cause import errors.

Then copy the zip from your server to your local machine:

```bash
scp user@123.456.789.123:/var/www/ghost/content/images.zip ~/Desktop/images.zip
```

Once unzipped, `images` should be the only top-level folder:

</Frame>

## Upload to Ghost(Pro)

Unzip your export, then upload each part to your new site in the order below.

### Content

Log into your new Ghost(Pro) site and go to **Settings → Advanced → Import/Export**. On the **Import** tab, click **Universal import**, select `export.json`, and click **Import**.

<Frame>
  <img src="/images/ghost-migration-universal-import.png" alt="The Universal import option in Ghost Admin's migration tools" />
</Frame>

### Routes and redirects

Go to **Settings → Advanced → Labs**. Under **Migration options**, click **Upload redirects** and select `redirects.yaml`, then click **Upload routes YAML** and select `routes.yaml`.

### Themes

Go to **Settings → Design & branding → Change theme**, click **Upload theme**, select the theme `.zip` from the `themes` folder, and activate it.

<Frame>
  <img src="/images/ghost-theme-upload-activate.png" alt="Uploading and activating a theme in Ghost Admin" />
</Frame>

### Images

How best to upload your images depends on the size of `images.zip`. A large file takes longer to upload and process.

If the file is under 500 MB, upload it with **Universal import**, the same way you imported `export.json`. If it's larger, split it into several smaller zips that keep the same folder structure.

If you have a very large image directory or run into errors, contact support and we'll help upload your images.

### Members

*Skip this step if you don't have members.*

If you have paid members, connect your new site to **the same Stripe account** you used before you import. Learn how in the [members guide](https://ghost.org/help/setup-members/#connect-a-stripe-account).

Then go to **Members**, click the settings icon, choose **Import members**, and select `members.csv`. You'll get an email when the import is complete.

<Note>
`post-analytics.csv` is included in your export for your records. Ghost(Pro) starts collecting analytics fresh from your first post.
</Note>
